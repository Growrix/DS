# Modern Australian Electrical Website Plan

## Purpose
This planning bundle defines a modern, lead-focused website direction for an electrical service provider targeting Australian homeowners and businesses.

The strategic goal is simple:
- increase phone calls
- increase qualified quote requests
- make trust obvious within the first screen

## Research-backed pattern summary
Modern electrical-service sites that convert well tend to repeat the same high-value behaviors:
- a full-bleed hero with immediate call CTA and a visible alternate quote CTA
- clear locality framing instead of generic nationwide language
- trust proof high on the page: licensed, insured, years active, review aggregate, response promise
- service segmentation that reduces decision friction: residential, commercial, emergency, switchboards, EV chargers, smoke alarms
- a sticky mobile call surface because high-intent visitors often convert on phone first
- short forms asking only what dispatch or quoting needs: name, phone, service, postcode, brief summary
- strong review and project proof instead of generic marketing copy
- service-area architecture that supports suburb or postcode SEO
- clear after-hours or same-day messaging, but only when true

## Recommended visual direction
- Archetype: local-business-trust
- Tone: modern, calm, clear, credible
- Palette direction: deep electric blue / navy base with warm amber CTA contrast
- Typography: humanist sans with large readable body copy
- Imagery: real electricians, vans, switchboards, EV chargers, commercial fit-outs, residential callouts
- Avoid: dark-default theme, stock-team photography, vague claims, over-animated hero content

## Lead-generation priorities
1. Make phone the fastest path on every primary route.
2. Give planners enough trust detail to call without extra research.
3. Use service pages to qualify intent before form submission.
4. Use suburb and project proof to improve local conversion.
5. Keep commercial buyers in the funnel with separate credibility language.
