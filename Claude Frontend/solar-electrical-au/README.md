# SolarTech Australia — Next.js 14

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Pages
- `/` — Homepage
- `/about` — About Us
- `/projects` — Project Portfolio
- `/contact` — Contact & Quote Form

## Customise Content
Edit files in `src/lib/data/` — no hardcoding anywhere.

## Tech Stack
Next.js 14 · TypeScript · Tailwind CSS · Lucide React
