# Optilux - Local Business Eye Care Template

A screenshot-first Next.js template for eye care and optometry websites, rebuilt in replica-strict mode from the Optilux reference screenshot pack.

## Tech Stack
- Next.js 16.2.6 (App Router)
- React 19.2.4
- TypeScript
- Tailwind CSS v4 (CSS-driven tokens)

- /faq
- /shop
- /shop/product-single
- /blog
- /blog/[slug]
- /contact

## Mode and Scope
- execution_profile: replica_strict
- screenshot_source_of_truth: true
- foundation attach: standalone_template
- no non-reference additive UI chrome included

## Brand Replacement
- Original brand text removed from output runtime
- Local brand used in template output: OptiLux
- Footer attribution kept as neutral template attribution
